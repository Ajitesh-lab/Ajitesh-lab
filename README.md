## Current
- **Margin** — a live handwriting tutor for GCSE science. Write with an Apple Pencil in the browser; strokes are recognised and checked against a mark scheme and a misconception list, and mistakes are underlined. I chose the architecture (stroke-based, not screenshot-based; local matcher first, then an LLM only when needed) and used AI to speed up implementation. Working prototype; still being polished. TypeScript · Next.js.
